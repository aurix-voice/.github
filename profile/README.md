<h1 align="center">Aurix</h1>
<p align="center">Open-source, self-hosted voice for games and real-time apps.</p>

Aurix is a complete voice stack you run yourself: one SFU with a native low-latency UDP protocol for
game engines and WebRTC for browsers, positional/3D audio, group end-to-end encryption, recording,
moderation and safety tooling, built-in TURN, horizontal scale with cross-node failover — and SDKs
for Unity, Unreal, Godot, Web and native C. AGPL-3.0 server, permissive client libraries.

| Repository | What it is |
|---|---|
| [aurix](https://github.com/aurix-voice/aurix) | Server, protocols, SDKs, docs, release pipeline — the whole platform |
| [Aurix Cloud](https://aurix.sh) | Hosted Aurix with managed capacity, regions and billing (closed source, [docs](https://aurix.sh/docs/)) |
